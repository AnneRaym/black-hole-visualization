# Black Hole Scientific Visualization

This project demonstrates scientific visualization of photon trajectories around a black hole using computational physics methods.

## Overview
The simulation models simplified photon trajectories influenced by gravitational effects and generates structured datasets for visualization.

## Features
- Numerical simulation of photon paths
- Data preprocessing using Python
- Visualization of trajectories and black hole shadow
- Pipeline compatible with tools like ParaView

## Tech Stack
- Python (NumPy, Pandas, Matplotlib)

## Future Extensions
- Integration with ParaView for large-scale rendering
- 3D visualization of geodesics
- Real Kerr metric implementation
